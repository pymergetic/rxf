# Historical design research

These documents preserve the reasoning that preceded the independent RXF implementation. They are not the current RXF specification or roadmap.

`metal-derived/` records the original analysis of Metal, metalpython, wasmmod, cards, seats, path surfaces, and self-hosting machinery that informed early RXF design. Terms and limitations in those files describe that historical substrate and must not be read as RXF requirements.

Current architecture begins at the repository [README](../README.md).
